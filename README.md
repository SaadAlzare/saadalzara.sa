# موقع سعد الزارع

موقع ثابت (HTML + CSS + JS) لا يحتاج أي تثبيت، منشور على GitHub Pages بالنطاق saadalzara.sa.

## إضافة برنامج جديد
1. ضع لقطات الشاشة وأيقونة البرنامج في `assets/projects/`.
2. افتح `projects.js` وانسخ كتلة «صفَحات» إلى القائمة، ثم عدّل قيمها.
   الحقول غير المطلوبة (مثل `tools` أو `stats`) يمكن حذفها.
3. احفظ الملف وحدّث الصفحة.

إذا وضعت لقطتين أو أكثر في `images` يظهر تحت الصورة زر للتبديل بينها، وتتبدل وحدها ببطء حتى يضغط الزائر.
الحقل `ui: true` في «صفَحات» يعرض نسخة HTML حية من واجهته بدل لقطات الشاشة (`assets/app.js`):
مبنية من ملفات البرنامج (ألوان الأدوات وأسماؤها ونصوصها وأيقونات Lucide)، فتبقى حادة على كل الشاشات،
ويستطيع الزائر النقر على الأدوات وتبديل المظهر. إذا أضفت أداة جديدة للبرنامج، أضفها في `TOOLS` و`GROUPS` و`OPTS` هناك.
خط الواجهة IBM Plex Sans Arabic (رخصة OFL). خط ثمانية لا يُستخدم في الموقع لأن رخصته تمنع رفعه على الويب.

قسم «ماذا يفعل صفَحات؟» (الفهرس الحي) مكتوب في `index.html` مباشرة، وحركة الصفحات لكل أداة في `assets/main.js` تحت «الصفحات تتحرك».

## تعديل النصوص والروابط
- الاسم والنبذة وروابط التواصل في `index.html`.
- الألوان والمقاسات في أعلى `assets/style.css` (متغيرات `:root`).

## ملاحظات
