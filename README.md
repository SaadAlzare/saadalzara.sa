# موقعي الشخصي

موقع ثابت (HTML + CSS + JS) لا يحتاج أي تثبيت. افتح `index.html` في المتصفح مباشرة.

## إضافة مشروع جديد
1. ضع صورة الشاشة في `assets/projects/` (مربعة، يفضَّل 1200×1200).
2. افتح `projects.js` وانسخ أي كتلة `{ ... }` إلى أول القائمة، ثم عدّل:
   الاسم، النوع (`web` أو `mobile` أو `desktop` أو `tool`)، السنة، الوصف، التقنيات، الصورة، والروابط.
3. احفظ الملف وحدّث الصفحة. أزرار التصفية وعدد البرامج في «نبذة» تتحدث تلقائيًا.

إن لم تكن لديك صورة للمشروع اترك `image: ""` وسيظهر غلاف تلقائي بألوان الشعار.

## تعديل النصوص والروابط
- الاسم والنبذة وروابط التواصل في `index.html`.
- الألوان والمقاسات في أعلى `assets/style.css` (متغيرات `:root`).

## النشر
ارفع المجلد كما هو إلى GitHub Pages أو Netlify أو Vercel.

## ملاحظات
- الخط: Alexandria (رخصة OFL، الملف في `assets/fonts/`).
- صور المشاريع الحالية والمشاريع الستة نفسها أمثلة توضيحية؛ استبدلها بمشاريعك.
